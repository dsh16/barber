# Бесплатная публикация

## Фронтенд — GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
Workflow `Deploy frontend to GitHub Pages` запускается при push в `main`, а также вручную
через **Actions → Deploy frontend to GitHub Pages → Run workflow**.

После успешного deployment адрес будет `https://dsh16.github.io/barber/`.
До успешного выполнения workflow этот адрес не подтверждён.
GitHub Pages должен быть доступен для типа и видимости вашего репозитория.

Nuxt генерирует статические файлы с префиксом `/barber/`. Node-сервер для фронтенда не нужен.
Без подключённого API сайт показывает сообщение о подготовке онлайн-записи.
Он не отправляет данные на localhost и не выдаёт фиктивные номера.

## PostgreSQL и API

1. Создайте бесплатную PostgreSQL, например в Neon, и скопируйте строку подключения
   с проверкой TLS, предоставленную провайдером. Для миграций используйте прямое
   подключение согласно рекомендациям провайдера.
2. В Render выберите **New → Blueprint**, подключите этот репозиторий.
   `render.yaml` создаёт только API на бесплатном плане; платная БД не создаётся.
3. В защищённых настройках Render задайте `DATABASE_URL`. Не публикуйте её в GitHub
   и не вставляйте в чат. Сервис запускает миграции перед API. Существующие данные
   миграция повторно не перезаписывает.
4. Проверьте `/api/ready` на выданном Render HTTPS-адресе:
   ответ должен быть `{"status":"ok","database":"connected"}`.
5. В GitHub **Settings → Secrets and variables → Actions → Variables** добавьте
   `PUBLIC_API_BASE` со значением `https://ВАШ-СЕРВИС.onrender.com/api`.
   Это публичный адрес, не пароль. Перезапустите workflow публикации Pages.

`CORS_ORIGIN` на Render настроен на `https://dsh16.github.io` без пути `/barber/`.
При смене домена измените его. Проверьте запись через опубликованную форму:
выберите мастера и услугу, введите тестовые контакты и получите номер.

Бесплатные тарифы имеют ограничения: сервис API может засыпать, первый запрос
после простоя — отвечать медленно. Условия и квоты провайдеров проверяйте при создании.
Каталог демонстрационный. Для приёма реальных клиентов замените его реальными
мастерами и услугами; публичная форма пока не включает защиту от массовых записей.
